# Netflix Clone

A responsive Netflix landing page clone built with HTML and CSS.

![Netflix Clone screenshot](assets/img/website-screenshot.png)

## Features

- Netflix-style hero section with background image
- Responsive feature sections with images and videos
- Language selector with English, Hindi, and Telugu options
- Email sign-up forms
- FAQ section with hover transitions
- Responsive layout for desktop and mobile screens

## Tech Stack

- HTML5
- CSS3

## Run Locally

1. Clone the repository.
2. Open `index.html` in a browser.

No build tools or dependencies are required.
